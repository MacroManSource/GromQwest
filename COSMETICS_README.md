# BaoMudao Profile Cosmetics Kit 1.0

Концепт визуального оформления профилей BaoMudao.ru.

## Содержимое
- `cosmetics.json` — единый каталог объектов для интеграции.
- `cosmetics.csv` — таблица для Excel / Google Sheets.
- `statuses/` — 16 бейджей статусов в SVG.
- `avatar_frames/` — 12 рамок аватара в SVG.
- `profile_effects/` — 8 декоративных эффектов и акцентов в SVG.
- `banners/` — 6 SVG-обложек профиля.
- `preview.html` — галерея всех элементов с фильтром по типу.
- `IMPLEMENTATION.md` — схема внедрения и заметки по безопасности.

## Принципы
- SVG масштабируется без потери качества.
- Иконки и обложки — исходники, их можно править в редакторе или прямо в коде.
- Статусы вроде «Модератор» и «Администратор» не должны назначаться пользователем самостоятельно.
- «Подтверждён» используйте только при реальной проверке.
- Косметика не должна перекрывать лицо на аватаре, мешать чтению или резко мигать.
