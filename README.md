# BaoMudao Live Customization Concept

## Как открыть
1. Распакуйте архив целиком — не отделяйте `index.html` от папок.
2. Рекомендуемый способ: открыть папку в VS Code и запустить `index.html` через расширение Live Server.
3. Также можно попробовать открыть `index.html` напрямую в браузере. Некоторые браузеры блокируют загрузку `cosmetics.json` через `file://`, поэтому при проблеме используйте локальный сервер.

## Что можно менять в реальном времени
- Имя и никнейм
- Основной и дополнительный статус
- Рамку аватара
- Эффект вокруг аватара
- Обложку профиля
- Цвет акцента и описание
- Видимость наград, статусов и рамок в разных местах

## Экраны
- Профиль
- Посты и комментарии
- Чаты (можно отправлять локальные демонстрационные сообщения)
- Коллекция элементов (нажмите на элемент, чтобы применить его)

## Содержимое
`index.html` — интерактивный интерфейс, `cosmetics.json` — каталог кастомизации, `statuses/`, `avatar_frames/`, `profile_effects/`, `banners/` — SVG-ресурсы, `award_icons/` и `awards.json` — значки достижений.

Это автономный визуальный прототип. Он не подключается к настоящему сайту или Supabase, не авторизует пользователя и не сохраняет настройки на сервере. Для реальной интеграции потребуется адаптация под структуру BaoMudao.
